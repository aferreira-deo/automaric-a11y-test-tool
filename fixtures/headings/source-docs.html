Configuration

The scanner reads one configuration file. Every option has a default, so the file can be left out.

The configuration file

The file is looked for in the working directory first, then in each parent directory.

scanner --config ./scanner.json

File format

JSON with comments. Unknown keys are reported and ignored.

Order of precedence

Command line flags win over the file, and the file wins over the defaults.

Options

timeout
Seconds to wait for a page before giving up.
depth
How many links away from the start page the scanner goes.

Note: a depth of zero scans the start page only.
